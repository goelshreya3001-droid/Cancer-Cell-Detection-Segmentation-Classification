What PathAI does

🧠
U-Net Segmentation
Pixel-accurate nuclei mask generation using a fully convolutional U-Net trained on CoNSeP colorectal tissue images.
🔍
Instance Separation
Watershed-based instance separation extracts individual nuclei from the binary segmentation mask.
📊
CNN Classification
Each 32×32 nucleus crop is classified into one of five phenotype categories by a dedicated CNN classifier.
🎨
Annotated Overlays
Colour-coded classification overlays help visualise the spatial distribution of nuclei types within the tissue.

Analysis Pipeline

📷 Input Image → 🎨 Stain Normalisation → 🧠 U-Net Segmentation → 🔍 Nucleus Extraction → 📊 CNN Classification → 📋 Results
