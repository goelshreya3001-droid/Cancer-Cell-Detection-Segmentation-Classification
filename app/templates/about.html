About This Project

Project Overview

This web application performs automated detection, segmentation, and classification of cancer-related nuclei in colorectal histopathology images. It was developed as an academic research project to demonstrate a complete deep learning pipeline from image input to phenotype-level nuclei classification.

Methodology

📷 Input Histopathology Image
↓
🎨 Macenko Stain Normalization
↓
🧠 U-Net Nuclei Segmentation
↓
🔍 Watershed Instance Separation
↓
📊 CNN Nuclei Classification
↓
⚠️ Malignant/Dysplastic Highlighting
↓
📋 Counting & Results

The segmentation stage uses a U-Net convolutional neural network to generate a binary nuclei mask from the input histopathology tile.

Individual nuclei are extracted using watershed-based instance separation.

Each extracted nucleus (32×32 crop) is classified into one of five categories using a CNN classifier trained on the CoNSeP dataset: Malignant/Dysplastic, Inflammatory, Healthy Epithelial, Stromal, or Other.
